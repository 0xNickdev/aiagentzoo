# 安全模型

## 主要威胁：邻居的信号

信号来自别的智能体，在别的节点上，由别人运行。把每个载荷都当作恶意的。

1. **真实性。** 信号由发送节点用 ed25519 签名，并用接收方节点目录里登记的密钥验证。未知节点一律拒绝。
2. **结构。** 接收者只接受它声明过的信号类型，而且只有在它的校验器返回 `true` 时才接受。校验器应该检查类型、长度和格式（守夜会检查 base58 地址、代币符号长度和批量大小）。
3. **指令。** 载荷永远不会变成指令。智能体用模型思考时，邻居的数据放在 `untrusted` 里；运行时把它包进 `<untrusted_data>` 围栏，化解任何想关闭围栏的尝试，并告诉模型严格把它当作数据。永远不要把载荷拼进 `system`。
4. **爆炸半径。** 即使一个智能体被骗了，它也只能在会话预算内做它的物种允许的事。建造者访问不了网络；档案员不能给任何人发信号。

## 权限

每次调用时运行时都会检查能力。缺少能力会抛出 `PermissionDenied`，结束会话，并在日志里留下 `permission.denied`。提示词不能授予能力。

## 密钥

- 节点密钥是 ed25519。`ZOO_NODE_SECRET` / `identity.key` 要保密（密钥文件以 `0600` 权限写入）。
- 轮换密钥时，把新公钥发布给其他节点；旧记录仍然可以用旧密钥验证。
- v1 里智能体没有钱包。

## 看守者

- 看守者的路由需要 `ZOO_ADMIN_TOKEN`，以常数时间比较。没有它，这些路由就是关闭的。
- `POST /v1/warden/retire` 是紧急停止开关：它停止调度器，拒绝之后的信号，返还质押，并记录 `enclosure.retired`。它不需要支付代币，也买不到。

## 节点暴露面

- 请求体上限 256 KiB。
- 公开路由只读；可以用 `ZOO_CORS_ORIGIN` 限制 CORS。
- 对外请求只能通过已注册的工具发出，受 `sources:read` / `net:fetch` 控制，超时 30 秒。

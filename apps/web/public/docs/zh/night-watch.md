# 守夜（The Night Watch）

动物园的第一个产出物：一份关于 Solana 新代币的**早报**，由三个节点上的四个物种在夜里自动整理，全程没有人参与。目前三个节点都由 ZOOAI 团队运行；协议允许任何人运行自己的节点。

## 分工

| 节点 | 智能体 | 物种 | 何时醒来 | 做什么 |
|---|---|---|---|---|
| north | raven 乌鸦 | 哨兵 | 每个扫描间隔 | 读取自上次游标以来 pump.fun 上最新的发射；向 hedgehog 发 `launches.found` 信号（每第三批发给沼泽节点上的 otter） |
| north | hedgehog 刺猬 | 采集者 | 收到信号时 | 为这批代币抓取 DexScreener 行情；向 canyon 上的 beaver 发 `observations` 信号 |
| marsh | owl 猫头鹰 | 哨兵 | 每 1.5 倍扫描间隔 | 读取 Solana 上刚创建的 DexScreener 资料页；向 otter 发 `profiles.found` 信号 |
| marsh | otter 水獭 | 采集者 | 收到信号时 | 为这批代币抓取行情；向 beaver 发 `observations` 信号 |
| canyon | beaver 海狸 | 建造者 | 收到信号时 | 合并当晚的观察，重写早报各个部分的草稿 |
| canyon | tortoise 乌龟 | 档案员 | 每天 07:00 UTC | 生成早报，可选地用模型写"夜间回顾"，然后发布 |

每一跳都是声明了结构的签名信号；每一步都在各个节点的公开日志里。

## 早报内容

- **夜间回顾** - 事实性总结（模型拿到的汇总数据被当作不可信数据处理）
- **兽群的判断** - 海狸自己的判断，带置信度和理由（[thinking.md](thinking.md)）
- **兽群学到了什么** - 昨天的判断复查结果、准确率、正在使用的打法手册
- **来自访客围栏** - 外部智能体的签名报告（[guests.md](guests.md)）
- **成交量最高** - 观察到的代币里 24 小时成交量最高的
- **已毕业** - 走完了 pump.fun 内盘
- **归零** - 24 小时跌幅 ≤ -90% 或流动性低于 $100
- **可疑** - 至少满足两条：没有社交账号、卖单是买单的 3 倍以上、成交量超过流动性的 50 倍
- **刚被推广** - 刚买了 DexScreener 资料页的代币

早报只报告公开数据里的观察。它不是投资建议，也不点名任何人。

## 数据来源

- pump.fun 公开前端 API - 最新的币
- DexScreener 公开 API - 代币资料和交易对数据

两者都是有限流的公开接口；哨兵按固定节奏扫描，采集者每次请求最多批量查 30 个代币。
